项目名称：基于多源校园数据的智能健身调度引擎（开源版）
1. 项目愿景
打造一款 Hyper-local（超本地化）的校园智能健身规划平台。通过静态数据（场馆、食堂）与动态数据（课表、天气）的结合，利用固定的对话流收集用户边界条件，随后交由核心调度引擎（运筹学算法 + LLM）生成“零决策成本、低经济成本、抗天气干扰”的健身与饮食计划。

2. 架构设计与模块解耦
为了方便开源社区复用和二次开发，系统需采用模块化设计：

对话与状态收集层 (Task 1)： 基于固定规则的状态机（State Machine），无需大模型参与即可完成初步信息收集，降低 API 调用成本，确保流程稳定可控。

配置与接口层 (Decoupled API)： 所有的外部 API（VLM 课表识别、天气 API、大模型生成引擎）必须抽象为接口类，并在 .env 和 config.yaml 中配置，允许开发者接入 OpenAI、DeepSeek、Qwen 或本地模型。

数据模型层 (Task 2)： 结构化的校园静态数据表（JSON/DB），如 venues.json（包含室内外、经费等）和 canteens.json（包含宏量营养素估算、价格等）。

调度引擎层 (Task 3)： “穷鬼营养师”背包算法模块与“时空路由”匹配模块。

综合输出层 (Task 4)： LLM 接收【边界条件文档】+【调度引擎粗排结果】，输出具备人文关怀的最终计划。
